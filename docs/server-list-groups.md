# Группы подписок в списке серверов

`ServerListControl` содержит один ScrollViewer и ItemsRepeater групп. Каждая
`SubscriptionGroupControl` использует штатный Expander с вложенным ItemsRepeater
строк. `ServerRowControl` оформляет отдельную строку стандартным ListViewItem;
родительской ListView и смешанного источника заголовков/серверов больше нет.

`ServerListViewModel.Groups` и `ServerListGroup.Rows` — стабильные коллекции.
Проекция поиска и сортировки согласуется по ID, сохраняя модели групп и строк.
Сворачивание меняет только IsExpanded: коллекции не очищаются и не наполняются
заново. Виртуализацией и освобождением невидимых элементов управляет WinUI.
Обновление задержки и прогресса рассылает уведомления конкретных свойств.

Видимый заголовок регистрируется как штатный ScrollViewer anchor. Перед изменением
высоты устанавливается anchor и выполняется один arrange; после изменения нет
ChangeView, отложенного восстановления координаты или подавления BringIntoView.
Заголовок вне viewport не назначается якорем. У нижнего края допустим сдвиг,
обусловленный уменьшением всей высоты содержимого.

Выделение хранится по ID в ServerSelectionState, независимо от созданных XAML-строк.
Поддержаны Ctrl, Shift, Ctrl+A, стрелки, Home/End, PageUp/PageDown, Space и Enter.
При сворачивании скрытые строки исключаются из массового выделения, текущий сервер
и подробности сохраняются; фокус строки переводится на штатный заголовок.
Активное подключение хранится отдельно. Двойной клик использует существующую
команду переключения с её проверкой доступности.

Заголовок подписки показывает название, число совпадений, время обновления,
расписание, расход/квоту, срок действия, ошибку и прогресс при наличии данных.
Обновление, проверка и меню вызывают существующие команды и сервисы.
Общая проверка задержки обрабатывает VisibleServers независимо от раскрытия.
Проверка группы захватывает все её серверы; контекстное меню — один сервер.

Поиск временно раскрывает совпавшие группы. CollapsedServerGroups в settings.json
хранит состояние вне поиска; записи последовательно проходят UpdateSettingsAsync.
Перетаскивание отключено, сохранённый порядок и сортировки поддерживаются.

## Проверки

`dotnet test XrayUI.Tests/XrayUI.Tests.csproj -c Release` проверяет в том числе
ID-выделение, диапазон и скрытие группы.

Опция сборки `LocalizationSmokeTest=true` запускает изолированный WinUI harness
с временными настройками, без запуска прокси. Проверяются реальная загрузка XAML,
выделение, неизменность коллекций при сворачивании, поиск и сохранение состояния,
координата заголовка во время анимации, быстрые переключения, локализация после GC.
На 50 группах по 100 серверов проверяются виртуализация и повторное использование
строк при переходе к далёкой группе. Проверка выполняется также в Native AOT.

`ServerBrowserProbe=true` оставляет отдельный минимальный стенд композиции
Expander + вложенные ItemsRepeater для диагностики поведения SDK.
