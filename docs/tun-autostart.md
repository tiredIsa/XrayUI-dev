# Автоподключение в TUN

`LastConnectionWasTun` хранит режим последнего успешного подключения. В отличие
от временного `IsTunMode`, оно не сбрасывается при остановке Xray и очистке маршрутов.
Старые настройки без этого поля используют `IsTunMode` как начальное значение.
Если старый выпуск уже сбросил его, нужно один раз успешно подключиться в TUN
после обновления приложения.

Автоподключение выполняется только при запуске с `--startup-minimized`.
Перед запуском Xray восстанавливается режим. Если для TUN не хватает прав,
приложение запрашивает обычное повышение через UAC и перезапускается с сохранением
признака автозапуска. Отмена UAC не запускает вместо TUN обычный прокси.
Повышенный экземпляр дожидается завершения предыдущего до автоподключения.

При включённых автозапуске и автоподключении начало TUN-подключения регистрирует
`XrayUI_Autostart` с `HighestAvailable`. Обычная задача использует `LeastPrivilege`;
переход с TUN на обычный прокси обновляет уровень задачи. При изменении настроек
автозапуска уровень определяется текущим/последним режимом. Задача привязана к
входу текущего пользователя, запускает приложение свёрнутым и не хранит пароль.

Если регистрацию или удаление задачи нельзя выполнить с текущими правами,
запускается короткий процесс того же приложения через `runas`. Он принимает только
фиксированные операции настройки своей задачи, проверяет совпадение SID аккаунта
и завершается до инициализации настроек, окна или сетевого состояния. Это не
фоновая служба. Отмена UAC оставляет настройки в исходном состоянии; ошибки
регистрации показываются пользователю.

Проверки без изменения автозапуска рабочей машины:

- unit-тесты XML задачи: права, пользователь, аргументы, пути с пробелами/амперсандами,
  поведение при работе от батареи и отсутствие ограничения в 72 часа;
- WinUI harness: сохранение последнего режима при записи устаревшего снимка очистки;
- Debug и Native AOT, включая отказ конфигурационного процесса при неверных аргументах.

Ручная проверка на тестовой машине: включить автозапуск и автоподключение,
подключить TUN, подтвердить UAC при необходимости, затем выйти и войти в Windows.
Приложение должно запуститься в трее, подключить TUN и не запрашивать UAC повторно.
Отдельно проверить отмену UAC, выключение автозапуска и переход на обычный прокси.
