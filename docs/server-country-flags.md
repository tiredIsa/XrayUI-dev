# Флаги стран серверов

Перед названием сервера показывается SVG-флаг страны его IP-адреса. Название узла
не используется для определения страны. Для доменного адреса выполняется обычный
DNS-запрос средствами ОС, затем локальный поиск в `Assets/rules/geoip.dat`, которая
уже поставляется с Xray. Запросов к внешним GeoIP API нет.

Индекс базы строится один раз в фоне. Чтение соответствует формату
[GeoIPList/CIDR в Xray](https://github.com/XTLS/Xray-core/blob/main/common/geodata/geodat.proto).
IPv4 и IPv6 поддерживаются, выбирается наиболее специфичная подсеть. Списки
провайдеров и обратные правила маршрутизации не считаются странами; PRIVATE
подавляет флаг. База маршрутизации даёт приблизительную географию IP, а не гарантию
физического расположения сервера или выходного адреса прокси.

Проверка запускается для реализованных строк ItemsRepeater. Одновременных проверок
не больше четырёх, таймаут DNS — пять секунд. Совпадающие имена используют общую
задачу и кэш на 30 минут; неизвестный результат кэшируется на пять минут. Кэш
ограничен по размеру и живёт в памяти до завершения приложения.

Для цепочек, неизвестных/локальных адресов, ошибок DNS и доменов, у которых IP
определены как разные страны, флаг скрыт. Замена модели или адреса не позволяет
запоздавшему DNS-ответу поставить старый флаг. Флаг не меняет подключение и не
записывается в конфигурацию сервера.

SVG-флаги поставляются локально из [flag-icons v7.3.2](https://github.com/lipis/flag-icons/tree/v7.3.2),
лицензия MIT включена в `Assets/Flags/LICENSE.txt`. Подсказка показывает название и
код страны. Emoji-флаги не используются.

Проверки: unit-тесты подсетей, границ, IPv6, PRIVATE, ошибочных protobuf-данных,
дедупликации/ограничения DNS и устаревших результатов. Изолированный WinUI harness
проверяет страну по поставляемой базе и загрузку SVG-флага, включая Native AOT.
